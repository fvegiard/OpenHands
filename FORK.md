# Fork branches (fvegiard/OpenHands)

`main` is an exact mirror of [All-Hands-AI/OpenHands](https://github.com/All-Hands-AI/OpenHands). Do not use it for personal or agent work.

| Branch | Purpose |
| --- | --- |
| `main` | Upstream OpenHands only (sync workflow) |
| `perso` | Default place to commit and open PRs |
| `dev` | Alternate integration branch |

Open PRs against `perso` or `dev`. Never against `main`.
